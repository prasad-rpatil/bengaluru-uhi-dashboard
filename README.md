# 🌡️ Bengaluru Urban Heat Island (UHI) Simulation Dashboard

An interactive Smart City dashboard that simulates the Urban Heat Island (UHI) effect across Bengaluru and demonstrates how sustainable interventions such as increased green cover, cool roofs, and water bodies can reduce urban temperatures.

---

## Features

- Interactive Streamlit dashboard
- Realistic Bengaluru zone-based simulation
- Dynamic heatmap visualization
- Historical green cover vs temperature analysis
- Before vs After intervention comparison
- Impact calculator for:
  - Energy savings
  - CO₂ reduction
  - Electricity cost savings

---

## Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
- Seaborn


---

## Installation

Clone the repository

```bash
git clone https://github.com/YourUsername/bengaluru-uhi-dashboard.git
```

Move into the project

```bash
cd bengaluru-uhi-dashboard
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Project

Interactive Dashboard

```bash
streamlit run app.py
```

Standalone Version

```bash
python standalone_demo.py
```
